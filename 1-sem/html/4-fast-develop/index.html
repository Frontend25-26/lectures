Поля:

key - Название пресета. Используется в Insert Snippet, если не задано поле prefix.

Можно использовать внутри синтаксис ${n:name}: n - номер заполнителя (переход между ними по нажатию на Tab), name - значение по умолчанию. Заполнители обходятся по порядку, начиная с единицы; ноль — это необязательный особый случай, который всегда идёт последним и завершает режим фрагмента с курсором в указанной позиции.
description - Описание пресета. Отображается перед вставкой кода.

Отступы

Отступы задаются через классы m, p, mx, py и т.д.

Tailwind использует числовую шкалу отступов, где 1 == 0.25rem (4px).

Например:

  • m-3 → margin: 0.75rem (12px)
  • py-6 → padding-top и padding-bottom: 1.5rem (24px)
  • px-4 → padding-left и padding-right: 1rem (16px)
  • pb-1 → padding-bottom: 0.25rem (4px)
