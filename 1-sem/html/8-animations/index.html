Переход

Переход – это анимация от одного набора CSS свойств к другому.

Для перехода необходимо:

  • начальный набор свойств (Ex: color: #f00;)
  • конечный набор свойств (Ex: color: #00f;)
  • Свойство transition – описание свойств и характеристик анимации перехода
  • Изменение свойств от начального набора к конечному (Ex: JS, :hover, :focus etc.)

CSS-свойство transition

transition: <property> <duration> <timing-function> <delay>;

transition-property

Устанавливает свойство, значение которого будет отслеживаться для создания эффекта перехода




transition-duration

Определяет продолжительность выполнения анимации




transition-timing-function

Устанавливает функциональную зависимость изменения свойства от времени 

transition-timing-function: ease|ease-in|ease-out|ease-in-out|linear|step-start|step-end|steps|cubic-bezier

cubic-bezier

Задаёт функцию изменения свойства в виде кривой Безье
P = (1−t)2P1 + 2(1−t)tP2 + t2P3
P1 = (x1, y1)
P2 = (x2, y2)
P3 = (1, 1)
t ∈ [0, 1]

Свойство animation

Позволяет анимировать переходы между ключевыми кадрами.
Для создания анимации необходимо:

  1. Определить ключевые кадры - содержат свойства, которые применяются в определенный момент времени при анимации.
  2. Применение анимации к элементу.

Ключевые кадры

@keyframes animationName {
    from {
        /*css свойства для первого кадра*/
    }
    to {
        /*css свойства для второго кадра*/
    }
}

Направление анимации

Направление анимации


                    animation-direction
  • normal — значение по умолчанию, анимация воспроизводится от начала до конца, после чего возвращается к начальному кадру.
  • reverse — анимация проигрывается в обратном порядке, от последнего ключевого кадра до первого, после чего возвращается к последнему кадру.
  • alternate — каждый нечётный повтор анимации воспроизводится в прямом порядке, а каждый чётный повтор анимации воспроизводится в обратном порядке.
  • alternate-reverse — аналогично значению alternate, но чётные и нечётные повторы меняются местами.

Стили ключевых кадров

Стили ключевых кадров


                    animation-fill-mode
  • none - значение по умолчанию, стили анимации не применяются до и после проигрывания анимации.
  • forwards — после окончания анимации элемент сохранит стили последнего ключевого кадра.
  • backwards - после окончания анимации к элементу будут применены стили первого ключевого кадра.
  • both — до начала анимации к элементу применяется первый ключевой кадр, а после окончания анимации элемент останется в состоянии последнего ключевого кадра.

# JS-HTML-HW-8 ## Шашки с анимацией --- ## Описание проекта Вам предоставлен шаблон для игры в шашки, включающий: - HTML-разметку с игровым полем - Базовые CSS-стили для доски и шашек - JavaScript-заготовку с функционалом создания доски и начальной расстановки фигур ## Задача Реализовать полноценную игру в шашки с анимацией следующих элементов --- ### 1. Ход шашек **Требования:** - Реализовать логику перемещения шашек по доске - При перемещении шашка должна плавно анимироваться к новой позиции - Использовать `Event Delegation` для обработки кликов на шашках и ячейках доски **Технология анимации:** `CSS transition` --- ### 2. Убийство шашек **Требования:** - Реализовать логику "съедания" шашек противника при перепрыгивании через них - При удалении шашка должна анимироваться, например, исчезать с эффектом масштабирования или затухания (Можно использовать гифку из `media/`) - Удалять шашку из DOM после завершения анимации **Технология анимации:** CSS `@keyframes` --- ### 3. Уведомление о победе **Требования:** - Определять момент победы одного из игроков (когда у противника не осталось шашек) - Создавать элемент уведомления о победе **динамически через JavaScript** (в исходной верстке таких элементов нет) - Отображать информацию о победителе **Технология:** JavaScript DOM API --- ## Критерии оценки 1. Корректная работа логики ходов шашек 2. Плавная анимация перемещения (CSS transition) 3. Корректная логика "съедания" шашек 4. Анимация удаления шашек (CSS keyframes) 5. Определение победителя 6. Создание уведомления о победе (JavaScript DOM) 7. Чистота и читаемость кода --- ## Дополнительные рекомендации (опционально) - Можно добавить визуальную индикацию выбранной шашки - Можно подсвечивать доступные для хода ячейки - Можно добавить звуковые эффекты - Добавить реализацию дамок
