Расположение элементов на странице и психология

Четыре важных принципа гештальга.
Гештальг с немецкого означает "образ". Теория группирования и выравнивания была разработана в начале ХХ века гештальт - психологами. Они описали несколько особенностей визуального человеческого восприятия.

Близость

Располагая элементы рядом один с другим, пользователи ассоциируют их друг с другом. На этом основывается группировка контента и элементов управления в пользовательском интерфейсе. Сгруппированные предметы связаны, разрозненные — нет.

Подобие

Предметы, похожие по форме, размеру или цвету, воспринимаются как связанные друг с другом.

Непрерывность

Наши глаза естественно следуют за прямыми и кривыми линиями, образованными расположением других элементов.

Смыкание

Мозг естественным образом «смыкает» линии, создавая простые замкнутые формы, такие как прямоугольники и окружности, даже если они формально не нарисованы.

Модульная сетка

Это система организации объектов в макете, основанная на колонках, рядах и отступах между ними. Чаще используется в графическом дизайне и полиграфии, то есть там, где пространство ограничено форматом листа

Современные способы раскладки flexbox и grid

Flexbox

Flex значит «гибкий»

Flex - это вид контейнера, который расширяет элементы, чтобы заполнить доступное свободное пространство, или сжимает их, чтобы предотвратить переполнение.

Чтобы сделать контейнер flex-контейнером нужно задать css-свойства display: flex;

свойство flex-direction меняет направление главной оси

flex-direction: row; (по умолчанию)
flex-direction: row-reverse;
flex-direction: column;
flex-direction: column-reverse;
Свойство justify-content управляет выравниванием флекс-элементов вдоль главной оси
justify-content: flex-start; (по умолчанию)
justify-content: flex-end;
justify-content: center;
justify-content: space-around;
justify-content: space-between;
justify-content: flex-start;
justify-content: flex-end;
justify-content: center;
justify-content: space-around;
justify-content: space-between;
Поиграться с justify-content https://developer.mozilla.org/en-US/docs/Web/CSS/justify-content#examples
Свойство align-items управляет выравниванием флекс-элементов вдоль поперечной оси
align-items: stretch; (по умолчанию)
align-items: flex-start;
align-items: flex-end;
align-items: center;
align-self позволяет переопределить у элемента внутри flex-контейнера выравнивание по поперечной оси
align-self: center;
align-self: flex-end;
align-self: stretch;
Поиграться с align-items https://developer.mozilla.org/en-US/docs/Web/CSS/align-items#result

Во flex-контейнере при переполнении элементы заполняются в том же ряду, но могут выходить за границы. За перенос во flex-контейнере отвечает свойство flex-wrap, и по умолчанию перенос запрещен: flex-wrap: no-wrap

flex-wrap: wrap;

flex-wrap: wrap-reverse;

При переполнении элементов во flex-контейнере образуются строки. Для управления расстоянием между строк есть свойство align-content. Оно распределяет свободное пространство по поперечной оси между строками флекс-элементов.

align-content: flex-start;

align-content: center;

align-content: flex-end;

align-content: space-between;

align-content: space-around;

Порядок элементов в flex-контейнере.

При помощи свойства order можно менять порядок отображения флекс-элементов внутри флекс-контейнера.

order: 0 (по умолчанию)

order: 1 (следующий по порядку)

{ order: 1 } { order: 2 } (чем больше значение, тем дальше элемент)

order: -1 (перед элементами с order по умолчанию)

flex: [flex-grow] [flex-shrink] [flex-basis];
свойство элемента во flex-контейнере

flex-grow

Может ли флекс-элемент занимать свободное пространство

flex-shrink

Как будет сжиматься флекс-элемент если места мало

flex-basis

Базовый размер флекс-элемента

flex-grow: 0 (по умолчанию)

flex-grow: 1

{flex-grow: 1} {flex-grow: 2}

flex-shrink (по умолчанию 1)
Чем больше значение у этого свойства, тем быстрее элемент будет сжиматься по сравнению с соседями, имеющими меньшее значение.

flex-shrink: 10 (элементы сжимаются сильнее остальныx)

flex-basis (по умолчанию берется из ширины или высоты)

flex-basis: 50% (занимает 50% ширины и 50% высоты)

Свойство flex позволяет управлять размерами flex-элемента. Шорткат, с помощью которого можно указать значение трёх свойств одновременно:
flex: [flex-grow] [flex-shrink] [flex-basis]

flex: initial;
flex: 0 1 auto; (по умолчанию)

flex: auto;
flex: 1 1 auto;

flex: 0 0 auto;

flex: 33.3%;
flex-basis: 33.3%;

flex: 2 0 50%;

Сетка

Когда нам необходимо расположить элементы в ряду или колонке, то удобно использовать Flexbox.

Если нужно сверстать сетку, или внутри контейнера передвигать элементы между строками и рядами, то удобно использовать Grid.

Но это не значит, что нельзя всегда использовать только flexbox
