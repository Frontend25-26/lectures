Принципы адаптивного дизайна

В адаптивной вёрстке выделяют несколько ключевых принципов, которые помогают сделать сайт удобным на всех устройствах.

1. Контент дублируется

  • Вся информация десктопной версии доступна на мобильной
  • Не заставляем пользователя искать данные на компьютере
  • Дизайнер переносит весь контент, ничего не удаляя
  • Контент — это смысл сайта. Его нельзя «обрезать» для телефона

2. Дизайн не меняется

  • Шрифты, цвета, логотипы одинаковы на всех устройствах
  • Пользователь узнаёт сайт, независимо от устройства
  • Адаптивность не должна разрушать визуальную идентичность

3. Сохраняется иерархия

  • Порядок блоков должен соответствовать целям сайта
  • Пример: «товар — описание и цена — заказ» для интернет-магазина
  • Нельзя менять логику для мобильной версии
  • Мобильная версия может выглядеть иначе, но идея сервиса и приоритеты должны сохраниться

4. Высота и ширина кнопок

  • Кнопки и интерактивные элементы — не меньше 44–48 px
  • На десктопе — мышь, на телефоне — палец
  • Если меньше — сложно попасть по элементу
  • UX мобильного сайта начинается с удобства нажатия.

5. Функционал десктопа повторяется

  • Функционал повторяется, даже если он сложный

6. Число колонок уменьшается

  • Десктоп: 12 колонок, мобильный экран: 1–4, планшет: 6–8
  • Компактное вертикальное расположение карточек
  • Горизонтальный скролл для второстепенных элементов

Подходы к адаптивной вёрстке

  • Mobile‑first — сначала для мобильных, потом для больших экранов
  • Desktop‑first — сначала для десктопа, потом адаптация под мобайл

Доля мобильного интернета в веб-трафике.

Mobile‑first

  • Базовая вёрстка — под маленький экран
  • Упор на минимализм, скорость, удобство на телефоне
  • Приоритетность основного контента (не заставляйте пользователя доскролливать до контента, ради которого он зашёл)
  • Хорош для сайтов с большим мобильным трафиком

Desktop‑first

  • Базовая вёрстка — для больших экранов
  • Удобен, если основной трафик — с ПК, или интерфейс сложный
  • Но может быть избыточным при просмотре с телефона

Пример

Адаптивный блок навигации:

  • На планшетах и десктопе располагается горизонтально
  • На мобильных устройствах располагается вертикально

Договоримся, что:

  • мобильные устройства: ширина экрана меньше 640 пикселей
  • планшеты: от 640 до 1024 пикселей
  • десктопные устройства: больше 1024 пикселей

Пример: Mobile‑first

/* стили для мобильной версии */
.burger-icon {
  cursor: pointer;
}

.navbar__links_list {
  display: flex;
  flex-direction: column;
  gap: 25px;
}

/* стили для планшетной и десктопной версий */
@media (width >= 640px) {
  .burger-icon {
    display: none;
  }

  .navbar__links_list {
    flex-direction: row;
    margin: 0;
  }
}

/* дополнительные стили для десктопа */
@media (width >= 1024px) {}

Медиазапросы

Медиазапросы позволяют менять стили под разные устройства и размеры экранов.

Синтаксис @media

  • Используется правило @media
  • Условия соединяются через not, and, or
  • Можно проверять:
    • ширину и высоту (width, height)
    • соотношение сторон (aspect-ratio)
    • ориентацию (orientation: portrait / landscape)
    • разрешение экрана (resolution)

Медиазапросы и свойства

width и height

Пример 
.box {
    width: 100%;
    max-width: 900px;
    margin: 0 auto;
    padding: 50px 10px;
    background: red;
    color: white;
    border-radius: 12px;
    border: 4px dashed white;
}

@media (min-width: 400px) {
    .box {
        background: orange;
    }
}

@media (min-width: 800px) {
    .box {
        background: green;
    }
}

Медиазапросы и свойства

aspect-ratio

Пример 
body {
  margin: 30px;
  background: black;
}

.box {
  width: 80vw;
  aspect-ratio: 16 / 9;
  background: pink;
  border-radius: 20px;
  border: 4px solid white;
}

Медиазапросы и свойства

orientation

Пример 
.layout {
  display: flex;
  gap: 10px;
  justify-content: center;
  align-items: center;
}

@media (orientation: portrait) {
  .layout { flex-direction: column; }
}

@media (orientation: landscape) {
  .layout { flex-direction: row; }
}

Медиазапросы и свойства

resolution

Можно подбирать стили и изображения в зависимости от плотности пикселей (DPI / dppx).

/* Retina / высокое разрешение */
@media (min-resolution: 2dppx) {
  .logo {
    background-image: url('hong@2x.png');
  }
}

/* Обычное разрешение */
@media (max-resolution: 1.99dppx) {
  .logo {
    background-image: url('hong.png');
  }
}

Брейкпоинт (breakpoint)

  • Брейкпоинт — это точка, при которой стили сайта меняются под новый размер экрана
  • Используется в медиазапросах как минимальная или максимальная ширина
  • Выбор брейкпоинтов зависит от макета и устройства, а не от стандартных размеров
  • Пример: 
    .container {
  padding: 16px;
}

@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
}
    Какой тут брейкпоинт?

Единицы для медиазапросов

  • Для width и height — px, em, rem, %, vh, vw
  • Для resolution — dpi, dpcm, dppx
  • aspect-ratio позволяет задавать соотношение сторон блока
  • Пример: @media (min-width: 480px) and (max-width: 1024px)

Mobile-first в коде

  • Базовые стили пишем для мобильного устройства 
    .container {
  padding: 16px;
}
  • Дальше используем медиазапросы для планшета и десктопа 
    @media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
}

Viewport

Что это и зачем
  • width=device-width — ширина под ширину устройства
  • initial-scale=1 — масштабирование по умолчанию
  • maximum-scale=1 — запрещает масштабирование выше 1
  • user-scalable=no — отключает масштабирование пользователем

Что такое Flutter?

  • Фреймворк для разработки мобильных, веб и десктоп приложений
  • Разрабатывается Google
  • Единый код для Android, iOS, веб и десктоп
  • Основан на языке Dart

Что такое Dart?

  • Язык, разработанный Google
  • Строгая типизация, но удобный синтаксис
  • Оптимизирован под работу с UI
  • Похож на JavaScript / Java / Swift

void main() {
  // Объявление переменных
  String name = "Alex";
  int age = 20;
  double score = 4.7;

  // Условие
  if (age >= 18) {
    print("$name взрослый");
  } else {
    print("$name несовершеннолетний");
  }

  // Цикл
  for (int n in numbers) {
    print("Число: $n");
  }

  // Функция
  String greet(String person) {
    return "Привет, $person!";
  }

  print(greet(name));
}

Что такое виджеты?

  • В Flutter всё — это виджет
  • Кнопка — виджет
  • Текст — виджет
  • Даже отступы и контейнеры — тоже виджеты
  • UI создаётся композицией виджетов

Widget build(BuildContext context) {
  return Column(
    children: [
      Text('Привет!'),
      Icon(Icons.star),
      SizedBox(height: 20),
      ElevatedButton(onPressed: () {}, child: Text('Кнопка'))
    ],
  );
}

StatefulWidget

Виджет с изменяемым состоянием.

Счётчик: 0


class Counter extends StatefulWidget {
  @override
  _CounterState createState() => _CounterState();
}

class _CounterState extends State< Counter> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        Text('Счётчик: $count'),
        ElevatedButton(
          onPressed: () => setState(() => count++),
          child: Text('Добавить'),
        )
      ],
    );
  }
}

  • Адаптивная вёрстка — про сайты и HTML/CSS
  • Flutter — про приложения, всё рисует сам
  • Вёрстка подстраивается под экран → в браузере

  • Обе технологии нужны, но для разных задач
