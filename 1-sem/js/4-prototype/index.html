Почти все в JavaScript это объект
Почему 🤔
Любая сущность в JavaScript наследуется от объекта. Все типы данных и структуры, кроме примитивных, являются потомками объекта. Поэтому у всех наследников объекта имеется набор общих методов: toString(), valueOf() и другие.

                        needWater: true,

Прототипом такого объекта становится Object.prototype

                        [[Prototype]]: Object,
                    };

Встроенные прототипы. Массив

Прототипом такого объекта становится Array.prototype

                        length: 1
                        [[Prototype]]: {
                            ...,
                            constructor: Array(),
                            [[Prototype]]: Object,
                        },
                    };

__proto__
__proto__(🗑) — это ссылка на prototype класса (функции-конструктора), с помощью которой был создан объект. Есть у любого объекта.

При поиске нужного свойства происходит переход по ссылкам __proto__, которые указывают на следующий прототип в цепочке. Если это последний прототип, то __proto__ указывает на null.

Свойство __proto__ — исторически обусловленный геттер/сеттер для [[Prototype]]

Флаги и дескрипторы свойств

Data descriptor

  • configurable – если true, свойство можно удалить, а эти атрибуты можно изменять, иначе этого делать нельзя;
  • enumerable – если true, свойство перечисляется в циклах, в противном случае циклы его игнорируют;
  • writable – если true, свойство можно изменить, иначе оно только для чтения;
  • value - значение которое лежит в этом поле

При создании объекта через литерал объекта, значения true

[[HomeObject]]

[[HomeObject]] - специальное внутреннее свойство для функций.

Когда функция объявлена как метод внутри класса или объекта, её свойство [[HomeObject]] становится равно этому объекту. Затем super использует его, чтобы получить прототип родителя и его методы.

super ссылается на прототип объекта из поля [[HomeObject]] 

                
                    let animal = {
                        name: 'animal',
                        voice() {  // animal.voice.[[HomeObject]] == animal
                            console.log(`${this.name} hello`);
                        }
                    };

                    let cat = {
                        __proto__: animal,
                        name: "cat",
                        voice() {         // cat.voice.[[HomeObject]] == cat
                            super.voice();
                        }
                    };

                    cat.voice();  // cat hello

Перебор свойств

Цикл for..in проходит не только по собственным, но и по унаследованным свойствам объекта

                        needWater: true,
                    };

                    let cat = {
                        __proto__: animal,
                        name: "cat",
                    };

                    for(let prop in cat) { // name, needWater
                        console.log(prop);
                    }

Почему метод hasOwnProperty не был выведен в цикле for...in?

Оно не перечислимо, внутренний флаг enumerable стоит false, как и у других свойств Object.prototype. Поэтому оно и не появляется в цикле.

Функция-фабрика

  • Функция-фабрика - это простая функция JavaScript, которая всегда создает и возвращает объект

Когда используется функция-фабрика?

Если нужно построить несколько объектов с похожими типами свойств и методами

                      name: 'Петр',

                        console.log(`Привет, я ${this.name}`);
                      },
                    }

                          return {
                            name: personName,
                            hi() {
                              console.log(`Привет, я ${personName}`);
                            },
                          }
                        };

                        const piter = person('Петр');

Если нужно организовать закрытые данные

                  
                    const piter = {
                      name: 'Петр',
                      hi() {
                        console.log(`Привет, я ${this.name}`);

                    let name = personName;
                    return {
                      get name() {
                        return name;
                      },
                      setName(newName) {

                      hi() {
                        console.log(`Привет, я ${this.name}`);
                      },
                    }
                  };
                  const piter = person('Петр');

Функция-конструктор...

  • Это особая функция JavaScript.
  • Вызывается с помощью клечевого слова new.
  • По соглашению имя начинается с заглавной буквы.
  • Не может быть стрелочной функцией.
  • Возвращает новый экземпляр, даже если явно ничего не возвращает. 
                      
                        function Product(name) {
                          this.name = name;
                        }
                        const book = new Product();

Что происходит, когда вызывается функция-конструктор?

  • JavaScript создает новый пустой объект внутри функции.
  • Новый пустой объект привязывается к ключевому слову this. Вновь созданный объект становится текущим экземпляром, и ключевое слово this ссылается на него.
  • Выполняются команды функции.
  • Наконец, функция конструктора автоматически возвращает этот объект в конце.

Для чего удобно использовать функцию-конструктор?

  • Уменьшаем дублирование кода
  • Можем лучше организовать свой код

  • Контролируем доступ к свойствам
  • Увеличиваем производительность за счет использования прототипного наследования

Различия между функцией-фабрикой и функцией-конструктором в JavaScript

  • В отличие от функции-фабрики, название функции-конструктора начинается с заглавной буквы
  • Функция-конструктор должна вызываться с помощью оператора new
  • Функция-фабрика всегда должна явно возвращать объект
  • Когда функция-конструктор вызывается с помощью оператора new, JavaScript автоматически создает и возвращает объект.
  • Функция-конструктор по умолчанию поддерживает прототипное наследование. Для функции-фабрики вы должны добавить прототипное наследование, используя метод Object.create()

Что важно помнить про наследование

  • Класс может быть отнаследован от другого класса с помощью ключевого слова extends
  • Наследование позволяет нам расширять классы, не дублируя код

  • В конструкторе дочернего класса вызываем конструктор родительского с помощью ключевого слова super

Статические свойства и методы класса

                  
                    class PrintPublication {
                      static publishingHouse = 'Ромашка';
                      static changePublishingHouse(value) {
                        this.publishingHouse = value;
                      }
                      static getPublishingHouse() {
                        return `Издательство '${this.publishingHouse}'`;
                      }
                      constructor() {}
                      release() {}
                      open() {}
                    }
                    var house = new PrintPublication();

                    PrintPublication.changePublishingHouse('Тюльпан') // Ок
                    PrintPublication.getPublishingHouse() // Издательство 'Тюльпан'
  • Статические методы и свойства определяются при помощи ключевого слова static и принадлежат классу, а не объекту
  • Статические методы используются для функциональности, принадлежащей классу «в целом»
  • Статические свойства используются, когда необходимо сохранять данные на уровне класса

Синтаксические ограничения для закрытых свойств в js

                            
                              class ClassWithPrivateField {
                                #privateField;

                                constructor() {
                                    this.#privateField = 42;
                                    delete this.#privateField; // Syntax error
                                    this.#undeclaredField = 444; // Syntax error
                                  }
                              }

                              const instance = new ClassWithPrivateField();
                              instance.#privateField === 42;
  • Пространство имен является общим для статических свойств и свойств экземпляра. Исключением является пара getter setter
  • constructor не может быть закрытым.
  • Ссылка на # извне класса является синтаксической ошибкой
  • Ссылка на закрытые свойства, которые не были объявлены в теле класса, так же является ошибкой
  • Нельзя удалить объявленные закрытые свойства с помощью delete

Закрытые свойства и наследование

                    
                      class Skill {
                        #canDance = true;

                        get canDance() {
                          return this.#canDance;
                        }
                      }

                      class Person extends Skill {
                        #canDance = false;
                      }

                      const girl = new Person();
                      console.log(girl.canDance); //true
  • Закрытые свойства не являются частью прототипической модели наследования, поскольку доступ к ним возможен только внутри тела текущего класса и они не наследуются подклассами
  • Закрытые свойства с одинаковым именем в разных классах совершенно разные и не взаимодействуют друг с другом

UseCase зачем нужны прототипы?

  • Приходилось бы постоянно возвращать разные объекты с множетсвом методов, что ударило бы по памяти и производительности
  • Так же он был популярен в ES5 (< 2015) и там для для упрощения создания объектов при помощи функций конструкторов был метод стандартный метод create его упрощённая версия: 
                          
                        Object.create = function(prototype) {
                          var Type = function () {};
                          Type.prototype = prototype;
                          return new Type();
                      };
    • Что позволяет создавать объекты без надобности использовать new и функции конструкторы в целом
