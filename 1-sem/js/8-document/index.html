Окружение в котором мы работаем

Window

window – это глобальный объект который представляет собой окно браузера и располагает методами для управления им. 

							
								window.close(); // закрыть окно браузера
								window.location; // получение информации о текущем URL
								alert(window.innerHeight); // получить высоту окна

Document

Каждая веб-страница, которая загружается в браузер, имеет свой собственный объект document. Интерфейс документа служит точкой входа для получения содержимого веб-страницы всего DOM - дерева, например такие элементы как body и table, а также обеспечивает функциональность, которая является глобальной для документа, например, для получения URL-адреса страницы или создания новых элементов в документе).

BOM

Объектная модель браузера (Browser Object Model, BOM) – это дополнительные объекты, предоставляемые браузером (окружением), чтобы работать со всем, кроме документа.

navigator даёт информацию о самом браузере и операционной системе. Например navigator.userAgent
location позволяет получить информацию о текущем URL
screen предназначен для получения информации об экране, на котором отображается текущее окно браузера. Например screen.orientation
frames Коллекция окон в window (дочерних для текущего окна)
history Предоставляет методы для работы с истории посещений, например history.back()
XMLHttpRequest Или кратко XHR - объект позволяющий делать запросы без перезагрузки страницы, как правило использующийся для загрузки данных

Навигация по DOM-элементам

Путешествие от одного узла к другому!

Относительная навигация

Получив необходимый элемент через document мы можем перемещаться в соседнии узлы любом направлении

Команды для навигации по DOM-нодам

В JS используются следующие команды применяемые к элементу DOM-структуры через точку.

parentNode Получить родительскую ноду
childNodes Все дочерние узлы (включая текстовые). Возвращает коллекцию
firstChild Первый дочерний узел
lastChild Последний дочерний узел
previousSibling Сосед слева
nextSibling Сосед справа

Аналогичные команды но для нод типа "элемент"

Команды для навигации по DOM-нодам типа "элемент".

parentElement Получить родительский элемент
children Все дочерние элементы. Возвращает коллекцию
firstElementChild Первый дочерний элемент
lastElementChild Последний дочерний элемент
previousElementSibling Соседний элемент слева
nextElementSibling Соседний элемент справа

Что использовать?

Свойство parentNode возвращает родительскую ноду, которая может быть узлом любого типа, включая элементы, текстовые и атрибуты. Если у узла нет родителя, свойство parentNode возвращает значение null. Свойство же parentElement возвращает родительский элемент указанного узла, который может быть только нодой типа "элемент". Это свойство игнорирует текстовые узлы и другие типы узлов и возвращает null, если узел не имеет родительского элемента. Хотя оба свойства возвращают ссылку на родительский узел или родительский элемент, важно использовать соответствующее свойство в зависимости от типа ноды, с которой вы работаете.

Селекторы элементов

Навигация это хорошо, но как получить точку отправления? В DOM есть для этого дополнительные методы поиска.

document.getElementById

Если у элемента присутствует уникальный атрибут id – мы можем получить данный элемент в JS вызовом document.getElementById(id)

Значение id должно быть уникально на весь документ

document.querySelector

Возвращает первый элемент соответствующий CSS-селектору

Можно использовать любого вида CSS селекторы и даже псевдоклассы

document.querySelectorAll

Принцип работы похож на предыдущий метод, но возвращает коллекцию всех элементов совпавших по CSS-селектору

getElementsBy*

getElementsByName, getElementsByTagName, getElementsByClassName.

Данные методы возвращают ссылки на коллекции которые могут изменяться с течением времени жизни документа, в отличии от метода document.querySelectorAll который возвращает слепок коллекции элементов на момент вызова.

Классы DOM - узлов

Разберём, что они собой представляют.

EventTarget Абстрактный класс для всех узлов, используется для работы с событиями
Node Так же абстрактный класс, обеспечивает навигационные методы изученные в предыдущем разделе parentNode, nextSibling, childNodes и пр.
Document Наследуется от HTMLDocument – точка входа в DOM
CharacterData Текстовые ноды и ноды комментариев
Element Базовый класс для DOM - элементов. Обеспечивает навигационные методы изученные в предыдущем разделе nextElementSibling, children, querySelector
HTMLElement Базовый классом для HTML-элементов, от него наследуются уже конкретные – например HTMLInputElement для input HTMLAnchorElement для гиперссылок и т.д.

Element.nodeType как способ узнать «тип» DOM-узла. 

							
								ELEMENT_NODE
								ATTRIBUTE_NODE
								TEXT_NODE
								CDATA_SECTION_NODE
								ENTITY_REFERENCE_NODE
								ENTITY_NODE
								PROCESSING_INSTRUCTION_NODE
								COMMENT_NODE
								DOCUMENT_NODE
								DOCUMENT_TYPE_NODE
								DOCUMENT_FRAGMENT_NODE

Node.tagName, Node.nodeName как способы узнать «тип» DOM-узла. 

							
								/**
								 * Свойство tagName есть только у элементов Element.
								 * Свойство nodeName определено для любых узлов Node.
								 * для элементов оно равно tagName
								 */
								document.querySelector('.line-numbers-rows').tagName
								// 'SPAN'
								
								document.querySelector('.line-numbers-rows').nodeName
								// 'SPAN'

innerHTML как способ влиять на документ.

Позволяет получить HTML-содержимое элемента в виде строки и перезаписать его! 

							
								// Все новые изображения и медиа-ресурсы будут перезагружены.
								// Скрипты запущены не будут.
								const el = document.querySelector('.content');

								el.innerHTML = 'Привет!';

innerHTML как способ влиять на документ. 

							
								const el = document.querySelector('.content');

								el.innerHTML += ', меня зовут Алиса!';

nodeValue, data – контент Node узла

textContent - безопасный способ изменить текстовый контент внутри узла. Все специальные символы и теги интерпретируются как текст

Атрибуты и свойства

Научимся различать эти два понятия, и поймём что и где применимо.

Для узлов-элементов большинство стандартных HTML-атрибутов автоматически становятся свойствами DOM-объектов. 

							
								document.getElementsByTagName('main')[0].id // page

Свойства

Ранее мы уже рассматривали свойства нод nodeType, nodeValue, data – эти свойства узлы DOM-дерева получают наследуя классы после парсинга HTML

Примеры стандартных аттрибутов, src, href, style, value и много других (зависит от класса элемента).

Методы для работы с аттрибутами

elem.hasAttribute Проверить на наличие (вернёт false или true)
elem.getAttribute Вернуть значение аттрибута
elem.setAttribute(name, value) Установить значение аттрибута
elem.removeAttribute(name) Удалить аттрибут
elem.attributes Вернуть список всех аттрибутов элемента

data-аттрибуты

data-аттрибуты можно получать в javascript через свойство dataset, при этом свойство переводится в camelCase. 

							
								const el = document.body.firstElementChild;

								console.log(el.dataset.userName); // Alisa

Изменение документа

Как создавать новые элементы и изменять уже существующие.

Создание документа, document.createElement 

							
								const el = document.createElement('img');

								el.setAttribute('src', 'https://catdomain.com/cat.jpeg');

Создание документа, document.createTextNode 

							
								const el = document.createTextNode('Я текст');
								const containerEl = document.getElementById('container');

								container.append(el);

Методы подключения элементов в документ

el.append Добавить элемент в конец el
el.prepend Добавить элемент в начало el
el.before Вставить по соседству - до
el.after Вставить по соседству - после
el.replaceWith Заменить элемент el - новым элементом

Удаление узла, el.remove() 

							
								const el = document.querySelector('.alisaMessage');

								el.remove() // узел будет удалён из документа

Клонирование узлов, el.cloneNode(true) 

							
								const el = document.querySelector('.alisaMessage');
								const newEl = el.cloneNode(true);

								el.after(newEl) // дубликат сообщения будет добавлен рядом

Устаревшие методы

el.appendChild(node) Добавить node в конец el
el.insertBefore(node, sibling) Добавить node перед sibling (дочерняя нода el)
el.removeChild(node) Удалить дочернюю ноду из el
el.replaceChild(newEl, node) Заменить одну из дочерних нод

Размеры и прокрутка, cистемы координат

Начинаем ориентироваться в пространстве.

Относительно окна браузера и относительно документа.

Получение координат node-узла elem.getBoundingClientRect() 

							
								const el = document.querySelector('.element');

								el.getBoundingClientRect() // получить координаты элемента

								/**
								 * Важно – все координаты относительно окна браузера!
								 *
								 * bottom - координата Y нижней границы прямоугольника
								 * left - координата X левой границы прямоугольника 
								 * right - координата X правой границы прямоугольника
								 * top - координата Y верхней границы прямоугольника
								 * height - высота элемента
								 * width - ширина элемента
								 * x - координата x левого-верхнего угла
								 * y - координата y левого-верхнего угла
								 */

Получение координат относительно документа 

							
								const el = document.querySelector('.element');

								const coords = el.getBoundingClientRect()

								console.log(coords.left + window.pageXOffset);
								console.log(coords.top + window.pageYOffset);
