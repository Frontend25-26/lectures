Что такое CSS‑переменные?

Хранение значений в одном месте + переиспользование по всему проекту

:root {
--primary-color: #3498db;
--font-size-heading: 2rem;
--spacing-unit: 8px;
}


.button {
background-color: var(--primary-color);
padding: calc(var(--spacing-unit) * 2);
font-size: var(--font-size-heading);
}

Базовые правила:


  • Имена регистрозависимы (--color и --Color — разные переменные)
  • Можно использовать дефисы и подчеркивания для разделения слов
  • Следует избегать зарезервированных слов CSS
  • Лучше использовать семантические имена, отражающие назначение переменной
    Плохо:                     Хорошо:

--big: 24px;          --color-primary: #0a66ff;
--c: #ff0000;         --color-danger: #ff0000;
--bg: #fff;           --layout-bg: #ffffff;

Глобальные и локальные значения

Глобальные — в :root,

:root {
  --bg: #fff;
  --text: #111;
}
.card {
  background: var(--bg);
  color: var(--text);
}

а локальные — внутри компонента

.card.dark {
  --bg: #222;
  --text: #eee;
}

Наследование переменных

Элементы автоматически наследуют значения родителей

body {
--text-color: #333;
}

/* Все элементы внутри body получат доступ к --text-color */
p {
color: var(--text-color);
}

Реализация темной темы

:root {
  --bg-color: white;
  --text-color: blue;
  --heading-color: red;
  --link-color: green;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-color: black;
    --text-color: white;
    --heading-color: pink;
    --link-color: yellow;
  }
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
  font-family: sans-serif;
  padding: 2rem;
}

h1 {
  color: var(--heading-color);
}

a {
  color: var(--link-color);
}

Реализация темной темы

function applyTheme(dark) {
      document.documentElement.style.setProperty('--bg-color', dark ? 'black' : 'white');
      document.documentElement.style.setProperty('--text-color', dark ? 'pink' : 'blue');
    }
applyTheme(true);


:root {
body {
background-color: var(--bg-color);
color: var(--text-color, #0066cc); // можно задать значение по умолчанию
}

Рекомендации по улучшению кода

  • Избегайте излишней вложенности переменных 
    /* Плохо */
:root {
  --primary-color: var(--main-color);
}

/* Лучше */
:root {
  --primary-color: #3498db;
}
  • Размещайте часто используемые переменные на уровне :root 
    :root {
  --text-color: #333;
  --bg-color: #fff;
  --primary-color: #3498db;
}

Рекомендации по улучшению кода

  • Локализуйте переменные до нужной области применения 
    .card {
  --card-bg: #ccc;
}
.card.sale {
  --card-bg: #e74c3c;
}
  • Используйте осмысленные имена 
    /* Плохо */
--blue: #3498db;
--big: 24px;

/* Лучше */
--color-primary: #3498db;
--font-size-lg: 24px;

Рекомендации по улучшению кода

  • Структурируйте переменные с помощью префиксов и группировки 
    :root {
  /* Цвета */
  --color-primary: #3498db;
  --color-danger: #e74c3c;

  /* Размеры */
  --space-sm: 8px;
  --space-md: 16px;
}
