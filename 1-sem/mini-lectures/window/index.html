Создание нового окна

url - ссылка на открываемый ресурс

target - имя контекста. Если контекста с таким именем нет, то открывается новое окно. (Можно использовать ключевые слова аттрибута target у <a>)

features - Строка, содержащая список параметров окна, разделенных запятыми, в формате name=value.

url

window.open();
window.open("https://itmo.ru");
for (let i = 0; i < 100; i++) {
  window.open("https://itmo.ru");
}

Почему не сработало?

Всплывающее окно блокируется в том случае, если вызов window.open произошёл не в результате действия посетителя (в большинстве браузеров)

target

window.open("https://itmo.ru", "ITMO");
window.open("https://en.itmo.ru/", "ITMO");

features

window.open("https://itmo.ru/", "ITMO", "popup=true");
window.open(
  "https://itmo.ru/",
  "ITMO",
  "popup,left=100,top=200,width=800,height=600" 
);

Результат window.open()

console.log(window.open("https://itmo.ru/", "ITMO"));

Окна имеют свободный доступ к содержимому друг друга только если они с одного источника (у них совпадают домен, протокол и порт (protocol://domain:port) ). 

const newWindow = window.open("https://itmo.ru/", "ITMO");
newWindow.onload = () => {
  console.log('load ITMO');
  let html = `
Добро пожаловать!
`;
  newWindow.document.body.insertAdjacentHTML('afterbegin', html);
};
const newWindow = window.open("/", "NEW");
newWindow.onload = () => {
  console.log('load NEW');
  let html = `
Добро пожаловать!
`;
  newWindow.document.body.insertAdjacentHTML('afterbegin', html);
};

Общение между окнами

postMessage

Интерфейс postMessage позволяет окнам общаться между собой независимо от их происхождения. 

window.postMessage(message [, options ])
window.postMessage(message, targetOrigin [, transfer ])
window.postMessage(message, {targetOrigin, transfer})

message - данные для отправки (Может быть любым объектом, данные клонируются с использованием «алгоритма структурированного клонирования») (в IE только строка -_- )

targetOrigin - источник для окна-получателя (проверка безопасности, что пользователь не перешел на другой сайт внутри вкладки)

transfer - список переносимых объектов (Transferable), которые не копируются, а перемещаются в получающий контекст

Получение сообщений

Чтобы получать сообщения, окно-получатель должно иметь обработчик события message. Оно срабатывает, когда было успешно передано сообщение.

Специальные поля event:

data - данные сообщения

origin - источник отправителя

source - ссылка на окно-отправитель. (Можно сразу отправить ответ, вызвав source.postMessage)

const newWindow = window.open(".");
newWindow.onload = () => {newWindow.opener.postMessage('Hello!')}
const newWindow = window.open(".");
newWindow.onload = () => {
  newWindow.opener.postMessage({
    date: Date.now(), 
    info: {
      clicked: true
    }
  })
}
