# 📘 Курс “Фронтенд-разработка” (ИТМО 2025–2026)

Этот репозиторий содержит материалы курса по фронтенд-разработке для студентов ИТМО.
Здесь собраны **лекции, домашние задания, квизы и результаты**, которые автоматически отображаются на сайте курса.

---

## 📄 Файл `lectures.json`

Основной источник данных для сайта курса.
Сайт **читает структуру лекций и домашних заданий из `lectures.json`** и отображает только актуальные материалы в зависимости от даты открытия (`openDate`).

### Пример структуры

```json
{
  "semesters": [
    {
      "name": "Первый семестр",
      "courses": [
        {
          "name": "Верстка",
          "lectures": [
            {
              "title": "Основы HTML",
              "link": "/1-sem/html/1-html/index.html",
              "openDate": "2025-09-27T10:00:00",
              "order": 1,
              "homework": "https://classroom.github.com/a/PtV9F7qh",
              "homeworkDate": "2025-10-12T23:59:59"
            }
          ]
        }
      ]
    }
  ]
}
```

---

## 📘 Описание полей `lectures.json`

| Поле                    | Тип               | Описание                                                 |
| ----------------------- | ----------------- | -------------------------------------------------------- |
| `semesters`             | array             | Массив семестров (1, 2 и т.д.)                           |
| `name`                  | string            | Название семестра                                        |
| `courses`               | array             | Блоки предметов внутри семестра                          |
| `course.name`           | string            | Название курса (например, “Верстка”, “JavaScript”)       |
| `lectures`              | array             | Массив лекций внутри курса                               |
| `lecture.title`         | string            | Название лекции                                          |
| `lecture.link`          | string            | Путь до HTML-страницы лекции                             |
| `lecture.openDate`      | string (ISO-8601) | Дата и время, когда лекция станет доступна               |
| `lecture.order`         | number            | Порядок отображения                                      |
| `lecture.homework`      | string            | Ссылка на задание в GitHub Classroom, квиз или иное      |
| `lecture.homework_text` | string (optional) | Текст-заметка вместо ссылки (например: “Квиз на лекции”) |
| `lecture.homeworkDate`  | string (optional) | Дедлайн выполнения ДЗ                                    |

## 🚀 Флоу добавления лекции и домашнего задания

### 🧩 1. Добавление новой лекции

#### Сценарий 1 — Новая лекция без ДЗ

1. Создай папку лекции, например:
   `/1-sem/js/5-arrays/index.html`
2. Добавь HTML-файл с содержимым лекции.
3. В `lectures.json` найди нужный курс (`"JavaScript"`) и добавь новый объект в массив `lectures`:

   ```json
   {
     "title": "Массивы",
     "link": "/1-sem/js/5-arrays/index.html",
     "openDate": "2025-10-25T12:30:00",
     "order": 5
   }
   ```
4. Сохрани изменения — страница появится автоматически в интерфейсе после наступления `openDate`.

---

#### Сценарий 2 — Лекция с домашним заданием

1. Добавь лекцию, как в сценарии выше.
2. Добавь поля для ДЗ:

   ```json
   {
     "title": "DOM и события",
     "link": "/1-sem/js/6-dom/index.html",
     "openDate": "2025-11-01T12:30:00",
     "order": 6,
     "homework": "https://classroom.github.com/a/a1b2c3d4",
     "homeworkDate": "2025-11-15T23:59:59"
   }
   ```
3. После этого ДЗ отобразится на странице `homeworks.html` с кнопкой перехода на GitHub Classroom.

---

### 📅 2. Обновление дедлайна или ссылки на ДЗ

1. Найди нужную лекцию в `lectures.json`.
2. Измени значение `homeworkDate` или `homework`.
3. Коммить изменения — данные обновятся на сайте.

---

### 💬 3. Лекция с квизом вместо GitHub Classroom

Если домашка проводится в формате квиза или очного задания, можно использовать `homework_text`:

```json
{
  "title": "Типы данных part. 1",
  "link": "/1-sem/js/1-types-1/index.html",
  "openDate": "2025-09-27T12:30:00",
  "order": 1,
  "homework_text": "Квиз на лекции 04 октября 2025 г.",
  "homeworkDate": "2025-10-04T12:30:00",
  "homework": "https://play.myquiz.ru/p/00875481"
}
```

---

### ⚙️ 4. Тестирование обновлений

После внесения изменений:

1. Открой `index.html` — проверь, что лекция отображается.
2. Проверь `homeworks.html` — убедись, что ссылка и дедлайн корректны.
3. Если используется `openDate` в будущем — лекция станет видна только после этой даты.

---

## 💡 Советы

* **Не меняй порядок вручную**, если можно просто использовать `order`.
* **Не удаляй старые лекции** — они остаются в архиве семестра.
* **Используй ISO-формат времени:** `YYYY-MM-DDTHH:mm:ss`.
* При добавлении новых семестров просто добавляй новый объект в `"semesters"`:


Если после добавления лекции она не отображается — проверь формат JSON и соответствие путей.
Ошибки обычно связаны с лишними запятыми, неправильным `openDate` или отсутствием `order`.
